# Quiz Game

A simple command-line trivia quiz game built with Python. It loads questions from a text file, shuffles the answer choices, checks your answers, and keeps track of your score.

## Features

- Randomly selects 5 questions
- Shuffles answer choices
- Checks answers and displays the correct answer
- Re-prompts when an invalid answer is entered
- Tracks your final score

## Requirements

- Python 3
- The `general.txt` question dataset

## How to Run

1. Download or clone this repository.
2. Make sure `general.txt` is in the project folder.
3. Open Command Prompt in the project folder.
4. Run `python main.py`

Replace `main.py` with your actual Python filename if it is different.
